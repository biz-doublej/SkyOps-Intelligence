# 항공사·공항 적용 정책 제안서

## SkyOps Intelligence 실시간 AI 관제 보조 시스템 도입 방안

---

### 1. 제안 배경

#### 1.1 현황 및 문제점

대한민국 주요 공항의 항공편 지연률은 연간 15~20%에 달하며, 이로 인한 경제적 손실은 연간 약 1조 원으로 추정된다. 현재 대부분의 공항 운영 시스템은 배치 기반으로 운영되어 실시간 대응이 어렵고, 이상 비행 패턴 감지 시 관제사의 경험에 의존하는 구조적 한계가 있다.

**핵심 문제:**
- 지연 예측이 사후적으로 이루어져 선제적 대응 불가
- 비정상 비행 패턴 감지 후 원인 분석에 과도한 시간 소요
- 관제 SOP 및 FAA 규정 검색이 수동으로 이루어져 의사결정 지연
- 승객 안내 방송이 수동 작성으로 일관성 부족

#### 1.2 SkyOps Intelligence 솔루션

본 시스템은 실시간 ADS-B 데이터 수집부터 AI 기반 지연 예측, 이상 탐지, 자연어 원인 설명까지 엔드투엔드로 자동화하는 통합 플랫폼이다.

| 기능 | 기존 방식 | SkyOps Intelligence |
|------|-----------|-------------------|
| 지연 예측 | 사후 통계 분석 | 15분 선행 실시간 예측 |
| 이상 탐지 | 관제사 육안 모니터링 | AI 자동 감지 + 알림 |
| 원인 분석 | 수동 SOP 검색 | LLM 자동 설명 + 규정 근거 |
| 승객 안내 | 수동 작성 | AI 자동 생성 (한/영) |
| 대시보드 | 레거시 시스템 | 웹 기반 실시간 지도 |

---

### 2. 도입 단계별 로드맵

#### 2.1 Phase A: 파일럿 도입 (3개월)

**대상:** 인천국제공항 관제탑 보조 시스템

**범위:**
- 실시간 항공기 위치 모니터링 대시보드 설치
- 이상 탐지 알림 시스템 (CEP 룰 기반, LOW 이상만)
- 지연 예측 참조 정보 제공 (의사결정 보조, 자동 조치 없음)

**필요 인프라:**
- GPU 서버 1대 (RTX 4090 또는 A100, vLLM 서빙용)
- Redis + Kafka 클러스터 (기존 공항 IDC 활용)
- 관제탑 내 모니터 1대 (대시보드 표시)

**예상 비용:** 약 5,000만 원 (서버 + 설치 + 3개월 운영)

**성공 기준:**
- 관제사 만족도 조사 70% 이상
- 이상 탐지 오탐률 30% 이하
- 지연 예측 정확도 80% 이상 (15분 기준)

#### 2.2 Phase B: 확장 적용 (6개월)

**대상:** 인천 + 김포 + 제주 3개 공항

**추가 기능:**
- LLM 기반 관제 어시스턴트 (FAA/ICAO 규정 QA)
- 승객 안내문 자동 생성 시스템 (항공사 연동)
- Prometheus + Grafana 운영 모니터링

**추가 인프라:**
- 공항별 엣지 서버 1대
- 항공사 API 연동 (대한항공, 아시아나 등)

**예상 비용:** 약 2억 원 (3개 공항, 6개월)

#### 2.3 Phase C: 전국 확대 (12개월)

**대상:** 전국 15개 공항

**추가 기능:**
- 공항 간 네트워크 지연 전파 예측 (Cascade Delay)
- H3 공역 혼잡도 기반 자동 경로 추천
- 다국어 안내문 (한/영/중/일)
- GCP Cloud Run 기반 SaaS 서비스 전환

### 3. 기대 효과

#### 3.1 정량적 효과

| 지표 | 현재 | 도입 후 기대 | 개선율 |
|------|------|------------|--------|
| 지연 대응 시간 | 평균 15분 | 평균 3분 | 80% 단축 |
| 이상 비행 감지 시간 | 수동 (수분~수십분) | 자동 30초 이내 | 95% 단축 |
| 승객 안내문 작성 시간 | 5~10분/건 | 5초/건 | 99% 단축 |
| 관제사 SOP 검색 시간 | 2~5분/건 | 즉시 (RAG) | 95% 단축 |
| 연간 지연 비용 절감 | — | 약 200억 원 | — |

#### 3.2 정성적 효과

1. **관제 안전성 향상**: AI 보조를 통한 이중 확인 체계 구축
2. **관제사 업무 부담 경감**: 반복 업무(안내문 작성, SOP 검색) 자동화
3. **승객 경험 개선**: 일관되고 신속한 지연 안내
4. **데이터 기반 의사결정 문화**: 실시간 대시보드를 통한 운영 가시성 확보

### 4. 법적·규제적 고려사항

#### 4.1 항공안전법 준수

- 본 시스템은 **의사결정 보조** 도구로, 최종 판단은 반드시 관제사가 수행
- 항공안전법 제84조(항공교통업무) 및 시행규칙에 따른 관제 절차 대체 불가
- AI 시스템의 오류가 안전에 영향을 미치지 않도록 "자문 전용(Advisory Only)" 모드 운영

#### 4.2 개인정보 보호

- ADS-B 데이터는 공개 방송 데이터로 개인정보에 해당하지 않음
- 승객 개인정보는 시스템에서 처리하지 않음 (항공편명만 사용)
- 관제 교신 데이터는 항공보안 관련 비식별 처리 후 활용

#### 4.3 AI 윤리 가이드라인

- 국토교통부 AI 활용 가이드라인 준수
- 모델 편향성 정기 점검 (항공사별, 공항별 공정성 평가)
- AI 판단 근거의 투명성 확보 (SHAP 해석, RAG 출처 표시)

---

### 5. 결론 및 제언

SkyOps Intelligence는 학부 캡스톤 프로젝트로 개발되었으나, 실시간 스트리밍 파이프라인(Kafka/Flink), ML 예측 모델(XGBoost), 도메인 특화 LLM(QLoRA+DPO), RAG 기반 관제 어시스턴트까지 엔드투엔드 시스템을 구현하여 기술적 실현 가능성을 입증하였다.

**핵심 제언:**

1. **단계적 도입**: 파일럿(3개월) → 확장(6개월) → 전국(12개월) 3단계 접근
2. **자문 전용 모드**: 초기에는 AI를 참고 정보로만 활용하여 안전성 검증
3. **데이터 확보 우선**: 한국 공항 실데이터 확보가 모델 성능 향상의 핵심
4. **관제사 참여 설계**: 현장 관제사 피드백을 반영한 UI/UX 개선 지속
5. **오픈소스 기반**: 벤더 종속 없이 자체 기술력으로 운영 가능한 아키텍처
