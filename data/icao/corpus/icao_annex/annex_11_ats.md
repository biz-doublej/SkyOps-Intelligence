# ICAO Annex 11 — 항공교통업무 / Air Traffic Services

## ATS 구성

**Air Traffic Services (ATS)** 는 다음 3 요소:
1. **Air Traffic Control Service (ATC)** — 충돌 방지 + 교통 흐름 원활화
2. **Flight Information Service (FIS)** — 운항 관련 정보 제공 (기상, NOTAM, 경보)
3. **Alerting Service** — 조난/실종기 수색 구조 지원

## 공역 분류 (ICAO Class A ~ G)

| Class | IFR | VFR | 분리 제공 | 비고 |
|-------|-----|-----|----------|------|
| A | ✅ | ❌ | IFR-IFR | High altitude |
| B | ✅ | ✅ | 모두 | Major terminal |
| C | ✅ | ✅ | IFR 모두, VFR-IFR | Medium terminal |
| D | ✅ | ✅ | IFR-IFR | Tower controlled |
| E | ✅ | ✅ | IFR-IFR | Controlled |
| F | ✅ | ✅ | Advisory only | Rare |
| G | ✅ | ✅ | 없음 | Uncontrolled |

## Coordination 요건

인접 ATC 유닛 간 **hand-off**는 다음을 포함:
- Aircraft callsign + type + SSR code
- Position + altitude (current + assigned)
- Track/heading + requests
- Estimated time over next waypoint

## ATS Routes / Airways

항공로는 **upper airways (ULL / UAxx)**, **lower airways (Bxx, Lxx)** 로 구분. RNAV/RNP 기반 PBN (Performance-Based Navigation) airways는 Q/T prefix (미국), Z prefix (유럽).

## FIR (Flight Information Region)

각국 상공을 FIR로 구획. 예: 대한민국 Incheon FIR (RKRR), 미국 ZNY (New York FIR). 국제 항로는 FIR boundary crossing 시 hand-off 필수. 공해 상공은 ICAO 지역 협의로 운영.
