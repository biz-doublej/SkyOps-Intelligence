# ICAO Annex 14 — 공항 / Aerodromes

## 공항 분류 코드

**Reference Code**: (runway length 기반) + (wingspan 기반) 조합. 예: 4E = runway 1,800m+ + wingspan 52-65m (B777 수용).

| Code Number | Runway Length |
|------|---------------|
| 1 | < 800 m |
| 2 | 800 ~ 1,200 m |
| 3 | 1,200 ~ 1,800 m |
| 4 | ≥ 1,800 m |

| Code Letter | Wingspan |
|------|----------|
| A | < 15 m |
| B | 15 ~ 24 m |
| C | 24 ~ 36 m |
| D | 36 ~ 52 m |
| E | 52 ~ 65 m |
| F | 65 ~ 80 m (A388 수용) |

## Runway Lighting

- **Threshold lights**: 활주로 시작, green
- **Edge lights**: 양쪽 가장자리, white (last 600m는 yellow = caution zone)
- **Centerline lights**: 활주로 중앙, 시정 저하 시 (CAT II/III)
- **Touchdown Zone (TDZ) lights**: 접지 구간 강조, pulsating white
- **REIL (Runway End Identifier Lights)**: 접근 시 식별, flashing white

## ILS 카테고리

| CAT | Decision Height | Runway Visual Range |
|-----|----------------|---------------------|
| I | 200 ft | 550 m |
| II | 100 ft | 300 m |
| IIIa | < 100 ft or none | ≥ 200 m |
| IIIb | < 50 ft or none | 50 ~ 200 m |
| IIIc | none | none (theoretical) |

CAT II/III 운영은 공항 + 항공기 + 조종사 모두 인증 필요.

## Rescue and Fire Fighting (RFF)

공항 RFF 카테고리 (1~10) — 최대 이·착륙 항공기 크기 기준.
CAT 9 (A388 수용 공항): 24,300 L 폼 + 450 kg 건조 화학. 대응 시간: 초동 3분, 전력 배치 4분.

## Obstacle Limitation Surfaces (OLS)

공항 주변 가상 표면:
- **Approach Surface**: 활주로 threshold에서 펼쳐지는 surface (슬로프 2%)
- **Transition Surface**: 측면
- **Inner Horizontal Surface**: 공항 위 반경 4,000 m 원반
- **Conical Surface**: Inner horizontal 바깥 경사면

OLS를 뚫는 장애물(건물/타워/산)은 **identified obstacle**로 등록 + 필요 시 lighting (red obstruction light).
