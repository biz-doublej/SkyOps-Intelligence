# FAA AIM — 공역 분류 / Airspace Classes

## Class A Airspace

18,000 ft MSL ~ FL600. 모든 운항은 IFR (Instrument Flight Rules) 필요. ATC clearance 필수. Mode C 트랜스폰더 장착 필수. VFR 불가.

## Class B Airspace

주요 공항(IAH, LAX, JFK, ATL 등) 주변. 지표면 ~ 10,000 ft MSL. 개별 공항마다 형상이 다름 ("upside-down wedding cake"). 진입 전 명시적 "Cleared into Class Bravo" 허가 필요. VFR도 가능하나 VMC + ATC 허가 조건.

## Class C Airspace

중규모 공항(DTW, ORF 등). 지표면 ~ 4,000 ft AGL. 양방향 무선 통신 수립 후 진입 가능 (특정 항공기 관제 허가 불필요, 단순 call-up).

## Class D Airspace

Control Tower 운영 공항. 지표면 ~ 2,500 ft AGL. 이륙/착륙 clearance 필요. VFR 허용.

## Class E / G Airspace

**Class E**: controlled airspace의 기본형. 대부분의 공역이 Class E (700 ft/1,200 ft AGL 이상). IFR은 ATC clearance 필요, VFR은 자유 (VMC 유지).
**Class G**: uncontrolled airspace. 산악 지역, 지방 저고도 공역. ATC 서비스 없음.

## Special Use Airspace (SUA)

- **Prohibited Area**: 비행 금지 (예: P-56 White House 주변)
- **Restricted Area**: 허가 필요 (군사 훈련 지역)
- **Warning Area**: 해상 12 NM 밖, 위험 경고 (fire-in)
- **MOA (Military Operations Area)**: 군사 훈련, VFR은 "see and avoid"
- **TFR (Temporary Flight Restriction)**: 임시 금지 (재난 지역, 대통령 이동 등)
